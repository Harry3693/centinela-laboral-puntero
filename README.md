# Puntero de la Librería — ZonaJobs Multiusuario

Repo público, sin datos sensibles. Un solo archivo (`puntero.json`) con el `scriptId` y la versión
publicada vigente de la Librería privada de Apps Script que usa el sistema Multiusuario de ZonaJobs.

Existe separado del repo principal (privado) para que las copias de los usuarios puedan leerlo sin
autenticación, vía la URL "raw" de GitHub — y para que sobreviva sin cambios aunque el día de mañana
cambie la cuenta de Google que administra el sistema.

No tocar a mano salvo que sepas lo que estás haciendo — lo actualiza el proceso de publicación de la
Librería.
